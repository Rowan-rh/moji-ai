## 一、 连机后一键构建与安装命令

连上手机 USB 并开启 USB 调试后，在终端执行以下命令：

```bash
# 1. 确认设备已连接且未打断前台使用
adb devices
adb shell dumpsys window | grep mFocusedApp

# 2. 编译并安装最新 QA 独立测试包（com.moji.ai.qa）
./gradlew assembleQa
adb install -r -g app/build/outputs/apk/qa/app-qa.apk

# 3. 启动「默记 QA」
adb shell am start -n com.moji.ai.qa/com.moji.ai.MainActivity
```
